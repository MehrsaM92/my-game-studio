# My Game Studio

Hello and welcome to My Game Studio!

This website is a place where I introduce and showcase different games.

Here you can discover information about various games, read their descriptions,
and share your thoughts through the comments section.

## About

My Game Studio is a personal game showcase website created to introduce
different games in a simple and organized way.

Each game can have its own title, description, and additional information.

## Features

- Game introductions
- Game descriptions
- Game information
- User comments
- Responsive website design
- Game management through an admin panel

## Technologies

- HTML
- CSS
- JavaScript
